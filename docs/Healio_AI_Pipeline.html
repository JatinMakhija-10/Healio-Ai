Architecture: Math-First v3  |  May 2026

Core Principle: The Bayesian MCMC engine has total authority over diagnosis. The LLM (Groq/Gemini) is a Natural Language Formatter only — it writes compassionate explanations and formats remedies, but never invents or overrides the diagnosis.

STAGE 1 — Bayesian MCMC Scoring (Mathematical Core)

1a. Condition Retrieval

Symptoms → Gemini embedding (768-dim vector) → Supabase vector similarity search → top 50 conditions. Falls back to keyword/location filtering if < 5 results.

1b. Symptom Correlation Detection

Checks for multi-symptom clinical patterns. Example: chest_pain + left_arm_pain + sweating + nausea = "Typical MI" → 5.0× multiplier.

1c. MCMC Bayesian Inference (per condition)

StepDescription
Covariate-Adjusted PriorBase prevalence × epidemiological rules. Age>45+male+smoker → 2.5× MI prior. BMI>30 → 1.8× DVT prior. Capped at 5×.
Log-LikelihoodWeighted symptom matching (sensitivity/specificity), location hard-filters, temporal reasoning, pattern boosts, unknown symptom marginalisation (CP6).
3-Chain MCMCMetropolis-Hastings with logit-scale proposals, 2000 iterations, 500 burn-in, 2× thinning.
Convergence CheckR̂ < 1.05, ESS ≥ 100, Geweke p > 0.05, acceptance rate 15-60%.
Prior SensitivityRe-run with weakened prior. If posterior barely changes → priorDominated.
Posterior PredictiveSimulate expected symptoms vs actual report. High PPP → model fits.
Red Flag EscalationP(Sepsis)>5% → antibiotics. P(STEMI)>5% → cath lab. P(Aortic Dissection)>2% → CT angio.

1d. Filtering & Ranking

Filter: score ≥ 8 → Sort: descending → Keep: top 5 as bayesianCandidates.

STAGE 1b — Convergence Gate (CP10)

If top candidate's MCMC did not converge (R̂ > 1.05, ESS < 100):

  1. Halt immediately — do not feed unreliable math to AI
  2. Use Information Gain Selector to find the single most discriminating question
  3. Return question to user → answer → re-run entire pipeline

STAGE 3 — AI Formatting (Natural Language Bridge)

Sends to /api/diagnose server-side:

  1. Multi-Query RAG: Embeds symptoms → retrieves Boericke Materia Medica chunks
  2. Enriched Prompt: Injects Bayesian priors + RAG + convergence warnings + DDI context
  3. AI Inference: Groq (primary) → Gemini (fallback)
  4. Structured JSON: description, rationale, remedies (with potencies/dosages), Indian home remedies, warnings, seekHelp flag

LLM's role: Format ONLY. Never invents conditions. Never overrides Bayesian confidence.

STAGE 4 — Uncertainty Quantification

Computes: confidence interval, evidence quality (strong/moderate/weak), calibration quality (excellent/good/moderate/poor), should-request-more-info flag.

Key Principles

1. Bayesian math owns the diagnosis — condition name & confidence from MCMC, never AI.
2. AI only formats — compassionate explanations, pre-verified remedies, RAG enrichment.
3. Intelligence layer only augments — adds safety, differentials, medication reasoning.
4. 100% fault-tolerant — any module failure is caught, pipeline continues.
5. Convergence-gated — unreliable MCMC → follow-up question, not garbage output.
